# ZeroMemories — proposed ADR-012 extension

**Status:** Concept proposal.

User-curated memory graph linking People, Places, Photos, Plans and Reflections. Suggest person-based albums from locally indexed EXIF, dates, user-approved contact tags and shared plans. Never assert that a photographed person was present without confirmation. EXIF coordinates are evidence of a photo location, not proof of who attended.

ZeroGallery references original files rather than duplicating by default; preserve originals, metadata, attribution, exportability, manual ordering, captions and album covers. ZeroMaps can show a private memory map of user-confirmed places, without requiring continuous location history.

Albums are private unless deliberately shared. Shared albums require explicit membership and E2EE design, with clear controls over exports and recipient copies. Allow exclusions for people, places, dates and sensitive memories. Automatic memory resurfacing must be opt-in.
